# Drawn grip

Per-weapon hand grip pose. Entity transform is the weapon root's local TRS when
parented under the character drawn mount (typically `prop_r`).

| Property | Value |
| --- | --- |
| Marker | Yes |
| Singleton | Yes (one per item prefab) |

## Fields

No configurable fields — `{ type: "drawn-grip" }` only. Pose is the entity
transform.
