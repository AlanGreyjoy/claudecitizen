# asteron-mcp

Stdio MCP server for live AsteronEngine editor context.

```bash
npm install --prefix tools/asteron-mcp
# AsteronEngine must be running (writes ~/.asteron/agent.json)
node tools/asteron-mcp/src/index.mjs
```

Configured for Cursor via `.cursor/mcp.json` as `asteron-engine`.

See `editor-desktop/README.md` → **AsteronEngine MCP**.
